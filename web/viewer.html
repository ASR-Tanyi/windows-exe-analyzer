What this report does — and what it does not

Static, read-only disassembly of file-backed executable bytes. Calls split blocks for clarity; a continuation edge assumes the callee returns. Function membership and role labels are conservative structural inferences.

PE entry is not necessarily main(). The PE header identifies the image entry point. Runtime startup and TLS callbacks are separate concerns. The Main shortcut exists only when an analyst provides a main RVA.

VAs use the preferred image base, not a live process load address. Unknown indirect targets stay unresolved. Supported reports include separate metadata and C-like views; neither proves complete source recovery. Imported targets are shown by name, not decompiled into DLL code.

Data view = original file bytes, not live memory. RIP/EIP-relative and constant-address memory operands link to their effective addresses. LEA forms an address without loading it. IAT slots are not resolved DLL addresses. Zero-fill, unmapped addresses and omitted bytes stay explicit. String and numeric interpretations do not establish source types.

No network requests or executable loading occur in this page. JSON label export is the portable way to retain edits. Browser storage for local files may be unavailable.
